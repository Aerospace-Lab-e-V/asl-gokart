# headunit


## Install

```
bun install
```

## Run

```
bun run start
```

## Make `Pi4`/`ODROID` image

```
bun run make:pi4
```

```
bun run make:odroid
```

### Output 

- Pi 4 image: `./out/make/deb/arm64/headunit_X.X.X_arm64.deb`
- ODROID image: `./out/make/deb/armv7l/headunit_X.X.X_armhf.deb`
